命名 = `域_核_窗` (代码里 PascalCase, 文档里 snake_case, 一一对应). 域 ∈ {ts, cs}: ts 的 A 域 = SELF (只看本资产), cs 的 A 域 = ALL (全截面) 或 GROUP (组内); 前缀只是 A 域的缩写, 不是独立分类. 窗只在 ts 有: `cum` 段内 expanding / `roll` 滚动 d / `ema` 指数递推, 无窗后缀 = 逐点 (cs 恒为逐点).
行序 = 全局 idx 序 (与 OpTable.hpp / op_check / GUI Operators 表一致), 序键: 元数 → 域 (ts 前 cs 后) → ts 按窗 (POINT/EXPAND/ROLL/EXPO) / cs 按 ALL→GROUP → 核类 → 名字字母序. 故同核的 cum / roll 不再相邻 (分属 EXPAND / ROLL 两块).
核类 (OpTable 语义列, 与窗正交): MAP 逐元素 / SHIFT 下标平移 / MOMENT 可和分解 (矩族) / EXTREME 极值及 arg 族 / ORDER 序统计 / RECUR 递推. GPU 方案列 = 实际 kernel 策略 (实现细节, 不在 OpTable 真相表里).
空格不是"未实现", 是按语义定的: `cum` (段内 = 当日) 只收**日内分布形状** → hhi / entropy 无 roll 版 (跨日滚动窗算集中度没有对应语义); `roll` (最近 d 分钟, 跨段) 只收**时序动态** → quantile / z / wma / product / slope 无 cum 版 (这几个要求窗长固定, 段内 expanding 的窗长随 t_D 变, 前后半段不可比, 自带一条 t_D 伪趋势). delay / delta 是 SHIFT 核只看一格, 天生只有 roll; ema 与 RECUR 核一一绑定, 仅 mean. 其余归约核 (sum / mean / var / std / skew / kurt / max / min / argmax / argmin / rank / cov / corr / beta / resid / wmean) cum 与 roll **成对齐全**, 缺一即 bug.
不入表的组合: 计数 `Σ1[x>k]` = `ts_gt` + `ts_sum_{cum,roll}` (占比换 `ts_mean_{cum,roll}`); 中位 = `ts_quantile_roll(k=0.5)` / `cs_quantile(k=0.5)`; 子集统计 = `ts_mask(x, 掩码)` 再套窗 (掩码由 `ts_todmask` / `ts_gt` 造); 超前相关 `corr(x_s, y_{s+k})` = `ts_corr_{cum,roll}(ts_delay_roll(x,k), y)`.
