# Lob/TS/OrderFlow/Flow 主动成交 / 新增委托 / 撤单
- `{amt,vol,n}_taker_{bid,ask}`: 主动买 / 主动卖的成交 额 / 量 / 笔. 侧 = **主动方** (吃单方) 的方向.
- `dlogp_taker_{bid,ask}`: 这些成交的 Σ 1e4·Δln(成交价) (基点, 相对上一笔任意成交; 原值): 主动买推高 / 主动卖压低了多少价.
- `{amt,vol,n}_maker_{bid,ask}`: **新增委托** 额 / 量 / 笔 = 所有新报进来的买 / 卖委托, 含到达即成交的进攻性委托, 也含挂在远档的; 不是 "被动成交".
- `{amt,vol,n}_cancel_{bid,ask}`: 撤单 额 / 量 / 笔 (侧 = 被撤委托的方向).
- `vol_maker_lim_{bid,ask}`: 以跌停价挂买 / 涨停价挂卖的委托量 (远离成交的 "彩票" 挂单; 封板时的排队也在这里).
- `vol_first30s`: 本分钟前 30 秒成交量. `vwap` / `twap`: 本分钟成交量加权 / 时间加权均价 (元, 不复权; 无成交沿用上一值).
- 机制: 主动成交是真实交易, 体现急迫 / 知情一方的方向; 委托与撤单可以是虚的 (挂了再撤), 体现的是挂单者的姿态.
- 坑: 额 / 量 / 笔是 `[对数]`: 买 − 卖 = ln((1+买)/(1+卖)) 可作失衡, 买 + 卖不是总量. vwap / twap 是原价, 要和本股别的价相比才截面可比.

# Lob/TS/OrderFlow/TradeSize 大笔主动成交 (按单笔成交额)
- `{amt,vol,n}_taker_{bid,ask}_ge_<阈>`: 单笔成交额 ≥ 阈值的主动买 / 主动卖 成交 额 / 量 / 笔; `dlogp_taker_{bid,ask}_ge_<阈>`: 这些成交的 Σ 1e4·Δln(成交价) (基点, 原值) = 大笔推价.
- 阈值: 固定金额 `4w` / `20w` / `100w` 元; 或本股前 5 日单笔成交额分位 `p50` / `p80` / `p84` / `p93` / `p95` / `p98` (个股自适应, 首日为 0).
- "≥" 是嵌套集 (≥100w ⊂ ≥20w ⊂ ≥4w); 全体 = Flow 的 taker.
- 机制: 大笔主动成交 = 急迫的大资金; 推了多少价 / 成交了多少额 = 冲击弹性.
- 坑: 按**一笔成交记录**的大小, 不是按委托: 一张大主动单扫多档会拆成多笔, 每笔都可能不够大. 按委托大小看用 OrderQuad.

# Lob/TS/OrderFlow/OrderQuad 委托维度大小单四象限
- 每笔成交的买方委托与卖方委托按**委托大小 (元)** 各分大 / 小, 落四象限 (首字母 = 买方委托, 次字母 = 卖方委托): `bb` 大买×大卖, `bs` 大买×小卖 (大买单吃散户卖盘), `sb` 小买×大卖 (散户接大单抛压), `ss` 小买×小卖; 再按主动方向分 `bid` (主动买) / `ask` (主动卖).
- 列: `{amt,vol,n}_od_{bid,ask}_{bb,bs,sb,ss}_<阈>` 额 / 量 / 笔. 阈值: `4w` / `20w` / `100w` 元; 或本股前 5 日委托申报额分位 `p50` … `p98` (首日为 0). 每个阈值各自一套完整分解, 不同阈值之间不是嵌套桶.
- 委托大小: 被动方 = 申报额; 主动方 = 截至本笔的累计成交额 (只用已发生的, 大单的前几笔会被记成小单).
- 机制 (边缘和): 大买单主动 = bid_bb + bid_bs; 大卖单主动 = ask_bb + ask_sb; 大买单被动接 = ask_bb + ask_bs; 大卖单被动挂出被吃 = bid_bb + bid_sb; 散户主动买 = bid_sb + bid_ss.
- 坑: 买卖任一侧不可信的成交被剔除, 四象限之和略小于 Flow 的 taker; 全部 `[对数]`, 边缘和不能直接相加.

# Lob/TS/OrderFlow/OrderLife 委托生命周期 (快被吃 / 快撤 / 到达即成交)
- 按委托从挂出到事件的存续时长 age 计, 只算在簿的**被动挂单**:
  - `{amt,vol,n}_fill_{bid,ask}_lt_<τ>`: 挂出后 < τ 就被对手**主动单吃掉**的成交. 侧 = 挂单自身方向: `fill_bid` = 买挂单被主动卖吃掉 (属于主动卖成交), `fill_ask` = 卖挂单被主动买吃掉 (属于主动买成交).
  - `{amt,vol,n}_cancel_{bid,ask}_lt_<τ>`: 挂出后 < τ 就被自己撤掉 (闪撤).
- τ ∈ {1s, 10s, 60s, 300s}, 嵌套集 (lt_1s ⊂ lt_10s ⊂ …); 全体 = Flow 的 taker / cancel.
- `n_marketable_{bid,ask}`: 到达即成交 (首笔成交时是主动方) 的委托**张数**, 一张扫多档只计 1 = 广义市价单个数; 与 Flow `n_taker` (成交笔数) 对比 = 每张主动单扫了几笔.
- 机制: 新挂的买单很快被砸 (fill_bid 多) = 卖方急迫, 在消化刚出现的买盘; 快撤 = 试探 / 虚挂 / 算法刷新报价, 撤的一侧是挂单者的方向 (cancel_ask 多 = 卖方挂单不实).
- 坑: **fill 的侧与主动方向相反**, 别把 fill_bid 当买方力量.

# Lob/TS/OrderFlow/Moment 单笔尺度的高阶矩
- `vol{2,3,4}_{taker,maker,cancel}_{bid,ask}`: 分钟内各笔 (主动成交 / 新增委托 / 撤单) 量的 Σ|O|², Σ|O|³, Σ|O|⁴ (股^k). 与 Flow 同侧的 vol / n 合出单笔量的分布: 例 Σ|O|² / Σ|O| = 量加权的平均单笔量 (越大 = 量集中在大单).
- `px{1,2}_maker_{bid,ask}`: 新增委托价的 ΣP, ΣP² (元; 市价单不入); 与 n_maker 合出平均委托价与委托价离散 (挂得远不远).
- `amt2_od_{bid,ask}`: 每张买 / 卖委托累计成交额平方的分钟增量 (不论主动被动); 日内累计 = Σ 各委托成交额² → 买 / 卖单集中度 (HHI ≈ amt2_od / 总成交额²; 高 = 成交集中在少数大委托).
- 坑: 幂和都是 `[对数]`: 对数相减 = 原量之比的对数 (ln(1+Σ|O|²) − ln(1+Σ|O|) ≈ ln 加权均笔量), 窗口内只能对数平均, 做不出原量的窗口和.

# Lob/TS/OrderFlow/MakerSeq 委托方向序列
- d = +1 买委托 / −1 卖委托 (所有新增委托按到达顺序, 不论大小、价位、是否成交).
- `dir_acf_maker_{1,5,20}`: 分钟内 d_τ·d_{τ−k} 的均值; 高 = 同向委托扎堆 (拆单、跟风、算法连续下单), 低 / 负 = 买卖交替 (做市式).
- `runlen_maker_{bid,ask}`: 分钟内连续同向委托段的平均段长; 买段长 > 卖段长 = 买方在连续拆单.
- 坑: 不分大小与激进度 (挂远档的小单也算); 无已结束段时 runlen 沿用上一值.

# Lob/TS/Book/Book 盘口状态 (分钟内时间加权)
- 每列 = 分钟内时间加权均值 (状态在两次盘口更新之间持有):
  - `spread_l{1,5,10}`: 第 N 个价位 (a_N − b_N) / mid (基点; 单个价位, 非前 N 档累计); `spread_w_{5,10}`: 前 N 档量加权价差.
  - `qty_{bid,ask}_{1,5,10,all}` / `amt_…`: 前 N 档量 / 金额深度 (all = 全簿单侧); `tlr_{bid,ask}_{1,5,10}`: 前 N 档占全簿比 (越大越易被击穿); `qty_eff_1`: min(一档买量, 一档卖量).
  - `obi_{1,5,10,all}`: (买量 − 卖量) / (买量 + 卖量) ∈ [−1, 1], 正 = 买方挂单厚.
  - `cost_{buy,sell}_{10w,100w,300w}`: 立刻吃掉 A 元的成交均价相对 mid 的偏离 (基点) = 冲击成本.
  - `micro` / `mid`: 量加权中间价 / 中间价 (元, 原价).
- 机制: 盘口是**被动方**的静态姿态 (挂单意愿与流动性). 厚的一侧常是阻力 (挂单墙) 而非推力; 价差宽 / 深度薄 = 流动性差、信息不对称大、冲击强.
- 坑: 挂单可撤可虚挂, 不等于成交; 分钟内全程无定义 → 沿用上一分钟值 (含跨日); 深度是 `[对数]`, 价差 / 失衡 / 成本是原值.

# Lob/TS/Volatility/Realized 已实现波动 (成交价网格)
- 在 3s / 15s 等距格上取成交价 (前一笔价) 得格收益 r (基点), 每分钟: `rv` = Σr², `rv_up` / `rv_dn` = 上行 / 下行半方差, `rm3` = Σr³, `rm4` = Σr⁴, `r_max` / `r_min` = 格收益极值, `bpv` / `tpv` = 双幂次 / 三幂次变差 (对跳跃稳健的连续部分), `rv_bigup` / `rv_bigdn` = |r| > 4σ (σ 由前一日估) 的大跳跃方差.
- `path_len` = Σ|1e4·Δln 成交价| 逐笔路径长 (基点).
- 机制: rv − bpv ≈ 跳跃; rv_up 对 rv_dn = 波动的方向不对称; path_len 对比该段收益的绝对值 = 来回震荡 (噪声交易) 程度.
- 坑: 无成交的格收益 = 0 (不活跃的票 rv 偏小); 幂和是 `[对数]`, 极值与 path_len 是原值.

# Lob/TS/Volatility/RealizedMid 中间价变化 (逐次盘口更新)
- 每次盘口更新 r = 1e4·Δln(mid) (基点), 每分钟: `rv_mid` / `rv_up_mid` / `rv_dn_mid` / `rm3_mid` / `rm4_mid` / `r_max_mid` / `r_min_mid`.
- 机制: 报价层面的波动 (不需成交); 与 Realized (成交价) 对比 = 成交价的买卖反弹噪声 vs 报价的真实移动.
- 坑: 事件型, 盘口更新越频繁和越大 (与活跃度混在一起); 无更新的分钟全 0.

# Lob/TS/Auction/Auction 开盘集合竞价
- 两阶段: `auc1` = 09:15–09:20 (可撤单), `auc2` = 09:20–09:25 (不可撤). 09:25 冻结, **当日之后每一行读到同一个值** (09:15–09:24 的行读到运行中的值).
- 委托 / 撤单: `{vol,n}_maker_{bid,ask}_auc{1,2}`, `{vol,n}_cancel_{bid,ask}_auc1`.
- 盘口: `n_snap` 更新次数, `n_snap_{up,dn}` 参考价上行 / 下行次数, `px` 阶段末簿价 (元), `px_{max,min}` 阶段内簿价极值, `qty_match` 阶段末虚拟匹配量, `qty_imb` 阶段末未匹配量 (正 = 买剩, 负 = 卖剩; `[对数]` 保号).
- 机制: 隔夜信息与开盘意愿; auc1 可撤 → 虚挂与诱导多 (撤单多 = 试探), auc2 不可撤 → 真实意愿; px_auc2 相对前收 = 开盘跳空.
- 坑: 全日同值, 截面根下全天同一排序; 价是原价, 要与 `bar.1d.pre_close` 等相比.

# Lob/TS/Basic/Kline 逐笔还原分钟 K
- `lob_open` / `lob_high` / `lob_low` / `lob_close`: 逐笔成交还原的分钟 OHLC (元, 不复权); 与 bar.1m 的 K 线同义, 数据源不同.
- 坑: 原价, 跨股不可比; 跨日 (除权) 要乘复权因子.

# Lob/TS/Basic/Tod 成交活跃度 · 同分钟 z 值
- x = 本分钟成交额 / 量 (主动买 + 主动卖); `lob_{amt,vol}_todz_{5,10}d` = (x − μ) / σ, μ / σ = 前 5 / 10 个交易日**同一分钟**的均值 / 标准差 (不含今天).
- 机制: 去掉日内 U 形与个股量级后的放量程度, 截面可比.
- 坑: 样本 < 3 或 σ = 0 → 0 (竞价空窗分钟恒 0); 单分钟噪声大.

# Lob/TS/Basic/Noise 白噪声对照
- `lob_noise`: 每行独立的噪声, 不含信息. 只作对照: 把式子的某一部分换成它成绩不变 = 那部分没起作用.

# Bar/TS/Basic/Kline K 线 (不复权)
- bar.1m `open` / `high` / `low` / `close`; 分钟箱 `<价>_<n>min` (首箱 = 09:15–09:30 竞价段); 日 `<价>_day`. 元, 不复权.
- 坑: 跨日 (除权日) 比较价格水平要乘 `bar.1d.adj_factor`.

# Bar/TS/Basic/Trade 成交量 / 额 (不分方向)
- bar.1m `volume` / `amount`; 分钟箱 `volume_<n>min` / `amount_<n>min`; 日 `volume_day` / `amount_day`. `[对数]`.
- 坑: 不分主动买卖; 分方向的在 Lob 档 Flow.

# Bar/TS/Basic/Tradable 可成交标记
- `can_buy_<层>` / `can_sell_<层>`: 行末能否买入 (未封涨停) / 卖出 (未封跌停), 0/1.
- 坑: 离散值, 不能直接作根输入; 只作条件或窗口频率 (封板频率).

# Bar/TS/Basic/Tod 成交活跃度 · 同 5 分钟箱 z 值
- `{amt,vol}_todz_{5,10}d`: 本 5 分钟箱成交额 / 量相对前 5 / 10 个交易日同一箱的 z 值 (不分方向; 样本 < 3 或 σ = 0 → 0).

# Bar/TS/Basic/Noise 白噪声对照
- `noise_gauss`: 每行独立的噪声, 不含信息, 只作对照.

# Bar/TS/Basic/Momentum 日频动量
- `ret_20d`: 后复权 20 日收益.

# Bar/TS/Fund/Fund 日频基本面与风格
- 盘中各行读到的是前一交易日收盘后的值 (日内不变). 价格限制 `lim_up` / `lim_dn` / `pre_close` / `adj_factor` 读到的就是当日适用值.
- 品类: 状态 (`ind_l1` 一级行业 id、`list_age`、`is_margin`、`is_susp`、`is_new`、`st_*`), 股本, 两融 (`rz_*` / `rq_*`), 财务三表 (`bs_*` MRQ; `pl_*` / `cf_*` 分单季 `_q` / 滚动 `_ttm` / 上年 `_lyr`; `roe_ttm` / `roa_ttm` / `dy_ttm` / `cfo_chg_ttm` / `*_yoy` / `days_since_report`), 行情风格 (`ret_12_1`, `ret_1m`, `turn` = 20 日均换手 / 250 日均换手, `ivol`, `resvol`, `beta`, `trend`).
- 用途: 微观结构信号的条件 (在哪类票上强) 或风格对照.
- 坑: 日内不变, 单独作根输入只给日间排序; 规模类量 (总资产、净利润) 与市值强相关.

# Bar/TS/Fund/Valuation 实时估值 (5 分钟箱末)
- `mcap` / `fmcap` (亿元), `pe_ttm` / `pb_mrq` / `ps_ttm` / `pcf_ttm` (市值 / 财务量, 亏损为负), `is_limit_up` / `is_limit_dn` (箱末价在涨 / 跌停), `is_low_px` (< 1 元), `is_low_mcap`.
- 坑: 比率在分母近 0 时极端 (用倒数口径的 `*_cs` 更稳); 标记列是 0/1.

# Bar/TS/Pool/PoolKey 池排序键
- `key_*`: 构造风格池用的日频键 (size / ep / bp / dy / roe / inv / mom / rev / turn / ivol / resvol / beta / trend / price / st / sst), 定义同 Fund / Valuation 的对应列; 母集外 NaN.

# Bar/CS/Basic/Kline 股价截面分位
- `close_cs`: 分钟收盘价去极值后的截面分位.

# Bar/CS/Fund/Fund 基本面截面分位 (日频)
- `dy_ttm_cs` / `roe_ttm_cs` / `roa_ttm_cs`: 行业 / 市值中性化后的截面分位; `cfo_chg_ttm_cs` / `rz_bal_cs` / `rq_bal_cs`: 去极值后的截面分位.

# Bar/CS/Fund/Valuation 估值截面分位 (5 分钟)
- `ep_ttm_cs` / `bp_mrq_cs` / `sp_ttm_cs` / `cp_ttm_cs`: 估值倒数经行业 / 市值中性化后的截面分位; `mcap_cs` / `fmcap_cs`: 市值截面分位.

# Bar/CS/Pool/Pool 风格池成员位
- `pool_*`: 0/1, 是否在该风格池 (交易日 D 用 D−1 收盘的池).
- 坑: 0/1 离散, 不能直接作根输入; 本作用域的池子固定, 与本池同名的那列在池内恒为 1.
