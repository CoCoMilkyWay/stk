# 特征清单 (L1 落盘, tick 触发) — 覆盖 checked.md 一、综述 全部因子

## 0. 边界

- 特征 = 单资产、因果、每行一个状态量 (L1 每分钟 / Fund 日广播). 不含全天归一. 跨日状态只允许 **短周期因果基准** (≤ 10 个交易日, 算子自持: 1.3 的 q 阈值 / 1.8 的 TOD μσ / 1.0 的跳跃阈值); 20 日以上的跨周量一律因子层做.
- 改动范围 = `Operator/` + `Method/Fundamental.cpp`. 不改 LOB / DataDefine 等基建; 需要基建配合的 (1.4 / 1.5 委托号) 单独批, 未批前不做.
- **不落 L0**: 所有 tick 级算子 compute=onTick/onDepth/onTaker/onMaker/onCancel, flush=onMinute. 秒级信息以"分钟内可加统计量" (Σr², Σr³, Σ|r||r₋₁|, 极值, 时间加权均值) 的形式降频, 日级量由因子层按行求和/取极值还原.
- 因子 = 特征上的算子: 日内聚合 (mean/std/skew/kurt/corr/OLS/分位/熵/FFT/排序) → 日频 → 跨日滚动 (5/10/20/60/120/240) → CS.
- 只把 **落盘后不可逆** 的参数做成多版本 (阈值 / 档位 / 时长桶 / TOD 基准日数 / 滞后阶). 可逆的 (日内滚动窗口 W、时段切片、累计求和、5 分钟重采样) 一律留给因子层, 不落列.
- 流量类特征一律落 **每分钟增量**; 时段量 = 因子层按行求和 (fp16 累计和精度差, 增量精度好). 现有累计比率列 (`ctr_*` / `cnbi_*`) 保留.
- 价差类 (`ret` / `range` / `body`) 必须独立落列: 由 fp16 价格反推的差分误差与差分本身同量级.
